Custom Tools (Unity)
Custom tools/scripts and etc. for easier work with Unity Engine.
Include various utilities and several tools:

Game Dev Utils - mostly exceptions and abstract scripts with basic functions.

User Interface Dev Utils - exceptions and scripts for UI.

Caching Objects Tool - caching scriptable objects plugin for override default scriptableObjeft parameters to unique in each field of objects.

Saveable Extension - save-load system with using JSON/Binary file formatters.

Vibration Plugin - vibration plugin for Android/IOS.

Virtual Mouse - virtual mouse for PC and Consoles.

Settings Menu - settings menu with custom settings for PC/Consoles and Mobile.

Multi-Scene Controller - controller to clean managing scenes.

Mini Map Utility - map tool with 3 type of render: render camera, navmesh area and baked sprite.
